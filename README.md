# Документація проекту Secure Vault Service

Цей каталог містить проєктну та технічну документацію сервісу захищеного зберігання секретів, організовану за підходом **Specification-Driven Development (SDD)** відповідно до стандартів ISO/IEC/IEEE 15289, 29148 та 42010.

## Структура документації:
- **`policy/`** — обов'язкові правила розробки, архітектурні обмеження та регламенти безпеки:
    - `project_policy.md` — стандарти коду, шарова архітектура, конвенції неймінгу, обробка помилок та тестування.
    - `security_policy.md` — політика криптографічного захисту, управління ключами та правила аудиту.
    - `privacy_policy.md` — правила поводження з конфіденційними даними та ізоляція метаданих.
- **`internal_spec/`** — внутрішні специфікації модулів та контекстів:
    - `Vault/business_logic.md` — специфікація доменної моделі, інваріантів, сутностей та життєвого циклу секретів.
    - `Vault/threat_model.md` — аналіз загроз предметної області (STRIDE) та контрзаходи.
