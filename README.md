# Специфікація проекту: Secure Vault Service

## 1. Загальний опис
Проєкт є захищеним сервісом для зберігання та управління секретами з обов'язковим веденням незмінного журналу аудиту (на основі стандартів ISO/IEC/IEEE 42010 та 29148).

## 2. Межі проєкту (Scope)
- **Що входить:** Модуль шифрування (AES-256-GCM), база метаданих, модуль аудиту подій, API доступу.
- **Що НЕ входить:** Процес управління сертифікатами SSL/TLS сервера, генерація паролів для користувачів.

## 3. Вимоги (згідно ISO/IEC/IEEE 29148:2018)
### Функціональні вимоги:
- Система повинна приймати текстовий секрет, шифрувати його та зберігати у БД.
- Система повинна записувати кожну спробу читання секрету в журнал аудиту без можливості видалення запису.

### Нефункціональні вимоги:
- **Безпека:** Дані в базі даних повинні зберігатися виключно у зашифрованому вигляді.
- **Продуктивність:** Час відповіді на запит читання секрету не повинен перевищувати 200 мс.
