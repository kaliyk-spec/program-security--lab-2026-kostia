# Політика безпеки (Security Policy) — Secure Vault Service

## 1. Криптографічні стандарти
- Усі конфіденційні дані шифруються виключно за алгоритмом **AES-256-GCM** (автентифіковане шифрування).
- Для кожного шифрування генерується новий криптографічно стійкий ініціалізаційний вектор (IV / Nonce) розміром 96 або 128 біт.
- Майстер-ключі шифрування ніколи не зберігаються у вихідному коді чи базі даних застосунку (передаються через змінні середовища / Key Vault).

## 2. Обробка конфіденційних даних у пам'яті
- Відкриті секрети не повинні потрапляти у логи, трасування або повідомлення винятків.
- Об'єкти подій (Domain Events) та DTO метаданих суворо ізольовані від зашифрованого та розшифрованого вмісту.

## 3. Аудит операцій
- Будь-яка спроба доступу, успішне читання, оновлення чи зміна статусу секрету генерує незмінний запис `AuditLog` (append-only).
