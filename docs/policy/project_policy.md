# Політика проекту — Secure Vault Service

| | |
| --- | --- |
| Назва | Політика проекту — Secure Vault Service |
| Версія | 0.1.0 |
| Статус | Draft |
| Класифікація | Internal |

Ця політика визначає обов'язкові вимоги до коду та архітектури Secure Vault Service — системи централізованого, криптографічно захищеного зберігання секретів. Ключові вимоги: строго типізоване ООП за SOLID, чистий код, шарова архітектура з примусовими межами між шарами.

## Правила зміни політики
- **Жодних змін мимохідь** — політика змінюється лише окремою задачею.
- **Окремий комміт** — зміни йдуть коммітом з префіксом `[POLICY]`.

## Технології
- **C# 12 / .NET 8**
- **Entity Framework Core** (Persistence)
- **xUnit & Moq** (Тестування)

## Фундаментальні принципи
- **Розділення шарів.** Змішування інфраструктурного шару та бізнес-логіки строго заборонене.
- **DDD для бізнес-логіки.** Реалізується в парадигмі Domain-Driven Design.33
- **Строго типізоване ООП, SOLID, чистий код**.

## Архітектура та структура
src/
├── Presentation/    # Контролери API (точка входу)
├── Application/     # CQRS (Commands/Queries), оркестрація
├── Domain/          # Бізнес-логіка (Entities, Value Objects, Policies)
└── Infrastructure/  # БД, криптопровайдери, зовнішні сервіси
